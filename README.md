# Cassava Fertilizer Prediction

## Project Description
This project focuses on predicting the appropriate type of fertilizer for cassava crops based on soil nutrient levels.

## Dataset
The dataset contains soil nutrient information such as:
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Soil type

The output is the recommended fertilizer type for cassava.

## Objective
To use machine learning to predict which fertilizer is required depending on the soil nutrient composition.

## Tools Used
- Python
- Pandas
- Scikit-learn

## Conclusion
The model helps in selecting the correct fertilizer for cassava based on soil nutrients.
